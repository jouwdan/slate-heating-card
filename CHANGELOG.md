# Changelog

## 0.1.0 — 2026-09-14

Initial standalone release preparation.

- Composable heating, hot-water and oil sections with a native HA visual editor.
- Standard climate controls across integrations, multiple zones/TRVs, target ranges, modes and presets.
- Water-heater and switch-based hot-water controls.
- Any number of ordered tank temperature sensors, with an optional interpolated hot-water estimate.
- Optional native Wiser boosts/programme editing and generic HA boost-script/schedule-entity hooks.
- Oil level and collapsed estimated usage/cost information; optional backend tracking example.
- Automatic section-based headings, responsive layouts and independent zone drafts.
- HACS metadata, installation and configuration documentation, sample screenshots and dependency-free tests.
- Legacy Wiser Slate type and single-entity configuration aliases retained.
